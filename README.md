# Due Fuochi — restaurant demo site (sample)

Scroll-driven film site: wood oven + dumpling kitchen story, menu, build-your-own, table booking and WhatsApp ordering.
Name, menu, prices, hours and WhatsApp number are placeholders.

Static files served by Caddy (Dockerfile). Deployed on Railway from this branch.
Footage: Pexels (free licence) — Ali Jafar, Be The Observer, Monsieur Sylvain, Mikhail Nilov.
